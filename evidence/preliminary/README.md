# Предварительная проверка

Этот прогон был выполнен на Linux отдельными процессами с S3-совместимым хранилищем RustFS. Его результаты зафиксированы до запуска на Windows.

- [Вывод Docker](docker.txt) показывает ошибку доступа к сокету в той среде.
- [Вывод Trino](trino.txt) и [лог потребителя](worker.txt) содержат результаты предварительного прогона.
- [Проверка компонентов и файлов Parquet](evidence.txt) фиксирует состояние сервисов и расположение файлов Iceberg.
- [Лог повторного чтения](replay.txt) и [таблица результатов](04-replay.png) подтверждают совпадение контрольных сумм двух таблиц до и после повторной обработки Kafka.

Подтверждённый запуск Docker Compose на Windows с Silo и результаты для сдачи приведены в [отчёте](../../отчет.md).
